<h1> U.S. Housing Finder 1.0 </h1>

This search tool enables users to efficiently find housing across the U.S. that meets their diverse needs (monthly rent, type, sq. feet, beds, baths, and state).
{Project 3 for DSA}

Note: The housing dataset used is outdated, but that does not impact the functionality provided by this search tool.

<h2> Features </h2>

- Read in listings from dataset into set or map data structure
- Switch seamlessly between the set and the map
- Search listings by monthly rent range
- Search listings by housing type 
- Search listings by square feet range
- Search listings by number of bedrooms
- Search listings by number of bathrooms
- Search listings by state
- Print all listings

<h2> Instructions for Installing and Running  </h2>

1. Fork this repository if you would like.
2. On this repository or your forked repository, click on Code.
3. In the Local tab, copy the HTTPS web URL.
4. Open your preferred IDE, and make sure you are on the startup screen.
5. Click Clone repository, and paste the web URL in the field.
6. Choose what path to clone it into, and click Clone.
7. Once cloned, link the premade CMakeLists.txt to this project if it asks you to.
8. Then, run the program with the U_S__Housing_Finder_1_0 executable selected.

The Console will guide you from there! We hope you enjoy!

For any issues that you may experience, contact grabermn3@gmail.com.
